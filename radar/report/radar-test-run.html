What the live site showed

Fixed in code

Four parsing bugs the stand-ins hid

  • Addressee is a multi-line block between the date and “Madam / Dear Sir”, often “The Chairpersons/ CEOs of …”. The code read only one line, so the UAPA circulars lost their NBFC addressee and scored 4.
  • Encoded characters such as &rsquo; and &ndash; were left in the text.
  • Reference numbers can include a department code (RBI/DPSS/2026-27/476). The code picked up a 2019 reference from further down the body.
  • “Applicability” first appears in the table of contents. The code now reads the paragraph itself.
Doc needs correcting

Three claims in the test results don't hold

  • The highest live score is 35 (the three UAPA updates), not 14. Nothing alerts either way.
  • Checking the title isn't enough for backfill. Ids 13742 and 13748 are different circulars (refs /296 and /302) with identical titles. The check now requires the PDF link to match as well.
  • Fetching a circular by Id worked today: Id 13748 returned its own circular. The earlier wrong-circular result didn't happen again.
Design limit

Backfill only reaches 3 Ids

The listing page shows 13 rows (Ids 13740–13752), only 3 more than the feed. A gap of more than 3 needs the month-by-month archive. The publish date and the date printed on a circular can also differ: Id 13746 is dated 26 Oct but published 27 Oct.
