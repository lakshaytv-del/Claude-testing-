What the run found

Fixed

Addressee check missed real wording

The check only recognised a fixed list of phrases. “All authorised non-bank Payment System Operators” didn't match, so the cyber Master Direction fell to the 0.1 default and scored 5. It now accepts any short line that starts with “All” and names an entity type, and the item scores 14 as expected.

Needs a decision

UAPA updates score 35, not ≤ 14

The doc says the highest live score was 14. Under the rubric as written, each sanctions-list update scores 1.0 × 50 × 0.7 = 35, because the rubric lists UAPA lists under KYC. That's still below 60, so nothing alerts either way. Either the doc line needs correcting, or UAPA updates belong in a lower-weight topic.

Not tested
